Этот проход меняет только `prom_app/frontend/`. Backend, корневой Compose и Dockerfile сохранены.

повторного применения CSV до завершения текущего сохранения.

## Рефакторинг

- [api/http.ts](src/api/http.ts): HTTP deadline, отмена, ошибки и проверка JSON отделены от протокола загрузки видео.
- [api/demoStorage.ts](src/api/demoStorage.ts): чтение, запись и сброс локальных данных имеют единые границы ошибок; [PlanRecovery](src/features/import/PlanRecovery.tsx) переиспользуется на площадке, в календаре и отчёте.
- [usePlayback](src/features/player/usePlayback.ts) владеет временем и состоянием медиа; обновление воспроизведения больше не перерисовывает всю страницу Site. Статическая SVG-сцена вынесена в [Scene](src/features/player/Scene.tsx).
- [ImportPlan](src/features/import/ImportPlan.tsx): валидация preview мемоизирована, чтение отменяется логически при закрытии/смене файла, сохранение защищено от повторного запуска. Инвалидируются только реестр и отчёт нужного объекта, без сброса настроек.

## Проверки

- Отдельный `npm run typecheck`, `npm run lint`, `npm run build` — успешно.
- **30 unit/integration-тестов** — успешно. HTTP deadline и abort проверены на локальном HTTP-сервере, который останавливает тело ответа после отправки заголовков.
- **23 Playwright E2E** — успешно: прежние сценарии и новые регрессии, включая настоящее видео длительностью 120 секунд и перемотку на 95-ю секунду.
- Сохранение выбранного времени после перезагрузки; отсутствие детекций при ошибке медиа; повтор загрузки; изоляция повреждённого плана; отмена/подтверждение восстановления; сохранность настроек и другого объекта.
- CSV с пустыми строками и переносом строки внутри кавычек, ошибки физических строк, сброс старого прогноза после импорта.
- Все пять экранов на 1440/1280/768/390 px, reduced motion, диалоги, PDF/печать и прежний API upload flow.
- `tools/verify-preview.mjs`: production preview и ошибочное значение режима — успешно.
- `tools/verify-production.mjs`: настоящий nginx 1.30.4, глубокие ссылки, видео, ошибки API/media/assets/fonts без подмены на SPA — успешно. Для Windows адаптированы только bind, filesystem root и пути логов.

Живые Gateway/MinIO и Docker в этой среде недоступны. Проверки upload с подменённым
транспортом не являются проверкой серверного стека. Новые серверные API и ML-функции
в этом проходе не добавлялись.

## Повторная проверка запуска и своего видео

Выполнена чистая установка `npm ci` по инструкции: lock-файл воспроизводится,
npm audit сообщает 0 известных уязвимостей. Повторно пройдены typecheck, lint,
30 unit/integration и **24 E2E**, build, preview и проверка nginx.

Добавлен реальный MP4/H.264: выбор файла, воспроизведение и возврат к нему через
историю браузера проходят без запросов к backend. При этом обнаружена и исправлена
ошибка: переход через ведомость на другой объект переносил параметры camera/recording/t
предыдущего объекта. Теперь оба способа выбора объекта очищают эти параметры,
сохраняя режим, период и фильтры. Тест сначала воспроизвёл ошибку на прежнем коде.

Уточнены инструкция запуска и срок жизни локальной записи: после перезагрузки
страницы или смены режима файл нужно выбрать заново. Отправка файла в MinIO требует
API-режима и работающего серверного стека; demo использует только локальный просмотр.
