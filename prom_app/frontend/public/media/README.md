# Синтетические записи

Все WebM в этой папке созданы из SVG-сцены приложения: это схемы, а не настоящая съёмка.
Ролики длительностью 60 секунд синхронизированы с детерминированными demo-наблюдениями,
содержат 12 состояний по 5 секунд. VP9, 1280×720, без звука.

Источник: `src/features/player/Player.tsx` (Scene/Vehicle) и `src/demo/observations.ts`.
Генератор: `tools/generate-demo-media.mjs`, нужен работающий Vite, Playwright Chromium и ffmpeg.
Внешние изображения и чужие видео не использованы.

Медиа является частью демо, а не результатом backend/ML.
