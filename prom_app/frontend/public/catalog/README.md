# Исходные данные справочника

Три JSON скопированы без изменения байтов из пользовательского архива
`data_by_gen_ai.zip`, переданного командой. Проверенная редакция: 18.09.2026.
Файлы, размеры, SHA-256 и версии перечислены в `manifest.json`.
ID комплекта назначен frontend: `construction-reviewed-2026-09-18`.

- construction_work_cards.json: 3.1-reviewed;
- construction_work_equipment.json: 1.1;
- construction_work_duration_review.json: 1.0.

Остальные версии из архива исторические или представляют аудит, они не смешиваются
с этим набором. Данные не являются утверждённым планом объекта или работающей моделью.
plan-example.csv — отдельный синтетический пример frontend, не исходник архива.
Обновлять JSON и манифест следует согласованным комплектом с новой версией;
профили старой версии требуют явного повторного сопоставления.
