# Синтетические снимки для демонстрации ТЗ

Четыре PNG получены из собственных синтетических WebM в `public/media`:
камеры 1–3 объекта north-park, позиции 0 и 15 секунд. Это растровые кадры
нарисованной сцены, а не фотографическая съёмка и не результат ML.

JSON-детекции заданы на основе той же сцены. SHA-256 относится к точным
байтам соответствующего PNG. `manifest.json` содержит кадры, результаты
и пример иерархического плана; он загружается кнопкой «Загрузить пример ТЗ».

Воспроизведение из каталога frontend:

```sh
node tools/generate-inspection-demo.mjs
```

Нужны установленные npm-зависимости и ffmpeg в PATH. Рабочий dev-сервер
не требуется. Перегенерация PNG может изменить их хеши в зависимости от
версии ffmpeg; генератор обновляет JSON и manifest одновременно.

Контракт импорта и ограничения: [ANALYSIS_CONTRACT.md](../../ANALYSIS_CONTRACT.md).
